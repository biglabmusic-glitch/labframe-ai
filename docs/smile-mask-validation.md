# Проверка локальной сегментации улыбки

Проверяется путь «готовый Worker приложения → локальные ONNX-веса → CPU/WASM →
предсказанная бинарная маска». Реально выполняется собранный `sam-smile-worker`,
не фиктивный ответ. Node worker_threads используется как среда исполнения для
проверки модели и протокола; это **не проверка браузера или Telegram на телефоне**.

Пользовательские фотографии и рабочие API в проверке не используются. Тестовый
fetch разрешает только чтение файлов модели на диске; внешняя сеть запрещена.
В модель не передаются URL фотографии. Sharp — только dev-зависимость для чтения
публичного тестового снимка и сохранения локальных QA-картинок.

## Публичные исходники

- Pawan.kumar1100, [Gummy Smile Woman.jpg](https://commons.wikimedia.org/wiki/File:Gummy_Smile_Woman.jpg),
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
  Снимок 600×400; атрибуцию и лицензию необходимо сохранять при передаче
  производных масок/изображений. Участие изображённого человека в LabFrame не подразумевается.
- NASA, Eileen Collins portrait, `skimage.data.astronaut`, public domain;
  [описание источника](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut).

Фотографии и производные QA-файлы хранятся в игнорируемой `.cache`, не входят
в интерфейс продукта. Конфигурации точек и контрольных участков — в `scripts/fixtures`.
Кропы и точки в этих тестах заданы явно: автоматическое обнаружение лица
MediaPipe и события касания в браузере этим тестом **не проверены**.

## Воспроизведение

После загрузки публичных исходников в `.cache/sam-qa/gummy-smile.jpg` и
`.cache/smile-qa/astronaut.png`:

```powershell
node scripts/prepare-mobile-sam.mjs
npm run build --prefix app
deno test --allow-net=deno.land --unstable-sloppy-imports scripts/test-smile-mask-region.ts scripts/test-mask-tools.ts
node scripts/test-mobile-sam-worker.mjs .cache/sam-qa/gummy-smile.jpg scripts/fixtures/smile-mask-one-tap.json .cache/sam-qa/one-tap-check
node scripts/test-mobile-sam-worker.mjs .cache/sam-qa/gummy-smile.jpg scripts/fixtures/smile-mask-gummy.json .cache/sam-qa/gummy-check
node scripts/test-mobile-sam-worker.mjs .cache/smile-qa/astronaut.png scripts/fixtures/smile-mask-portrait.json .cache/sam-qa/portrait-check
```

Проверяются: одно центральное касание; несколько зубов с отрицательными
касаниями на десне/нижнем ряду; отказ на неоднозначных подсказках; маленький
кроп улыбки портрета. Контрольные прямоугольники внутри эмали должны быть
покрыты, а выбранные участки десны/нижних зубов/губ — оставаться вне маски.
Это несколько локальных контрольных областей, **не полная экспертная разметка**.
Нельзя интерпретировать их результат как Dice/IoU всей улыбки или клиническую точность.

## Результат разработки

На рабочем компьютере: подготовка около 2.5–2.6 с, одно касание около 0.15 с,
несколько зубов с исключениями около 0.8 с. Главный цикл Node продолжал
работать во время вычисления в Worker. Пиковый RSS всего тестового процесса
около 0.6 ГБ; в него входят Node, тестовые изображения, Worker и WASM.
Мобильный расход памяти и задержки не измерены. В проверяемых участках десна и
нижний ряд исключены, два участка центральных верхних зубов покрыты полностью.
Маски также просмотрены визуально: мелкие пропуски у границ возможны.

Полноценный прогон в браузере был остановлен Computer Use: инструмент не смог
установить текущий URL окна Chrome. Больше UI-действий и обходов этого ограничения
не выполнялось. Перед расширением пилота требуется проверка загрузки модели,
касания +/−, zoom/pan, сброса точек, замены фотографии и отмены на телефоне в Telegram.

Модель универсальная, без обучения на стоматологической разметке. Автоматические
подсказки и маски остаются предварительными. Для нестандартной анатомии,
сомкнутого прикуса, размытия, бликов и слабых границ нужен ручной контроль.
